快捷键一览

      

        
          
快捷键功能说明

        
        
          
Ctrl + Z撤销当前用例或环境变量修改（与顶部 ↶ 按钮同步，编辑框内外均可撤销）

          
Ctrl + Y / Ctrl + Shift + Z重做已撤销的修改（与顶部 ↷ 按钮同步，编辑框内外均可重做）

          
Ctrl + S保存当前用例或环境配置

          
Ctrl + Enter在「接口调试」页发送请求；在「自动化用例」页保存并运行当前用例

          
Ctrl + F切换到「自动化用例」页并聚焦用例搜索框

          
Ctrl + N新建自动化用例（非输入框聚焦时）

          
Ctrl + 1 ~ 4快速切换左侧 4 个功能页（调试 / 用例 / 环境 / 报告）

          
F1打开或关闭本快捷键一览弹窗

          
Esc关闭当前打开的弹窗
